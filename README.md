# 🎮 Kimaya & Los Secretos del Bosque Ancestral (Proyecto Uni)

Videojuego 2D/2.5D desarrollado en **Unity 2022.3 LTS** con arte generado mediante **PixelLab AI (MCP)**.

---

## 🗺️ Mapas y HUB del Juego (PixelLab AI)

> 📁 Para ver todos los mapas y recursos en alta resolución, visita la carpeta [`/Mapas`](Mapas/README.md).

### 🌲 Mapa Principal del HUB: Claro del Bosque con 3 Portales
![Hub Bosque Pro](Mapas/01_Hub_Bosque_Pro_3Portales.png)

El punto de encuentro inicial donde Falin y Mía parten hacia cada aventura:
- 🟢 **Portal Izquierdo (Verde):** Nivel 1 — *Templo del Bosque (Rescate de Kiara)*
- 🔵 **Portal Central (Azul):** Nivel 2 — *Cuevas del Zarzal*
- 🟣 **Portal Derecho (Morado):** Nivel 3 — *Altar de Fuego (Desafío Final)*
- 🏛️ **Círculo de Piedra Central:** Plataforma de reaparición con runas ancestrales.
- ⛰️ **Montañas y Pinos:** Límites naturales del mapa.

---

## 🐕 Protagonistas

- **Falin (San Bernardo):** Fuerza bruta, empujar bloques pesados y ladrido sónico que aturde enemigos (`Ladrido Protector`).
- **Mía (Schnauzer):** Agilidad, rastreo de huellas ocultas con olfato (`Olfato Mágico`) y sigilo para pasar por túneles estrechos.

## 🕹️ Controles Principales

| Acción | Teclado |
| :--- | :--- |
| **Moverse** | Flechas / `A` `D` / `W` `S` (Hub) |
| **Saltar** | `Espacio` |
| **Cambiar Personaje** | `Tab` / `Q` |
| **Poder de Falin (Ladrido)** | `F` |
| **Poder de Mía (Olfato)** | `E` / `Shift` |
| **Interactuar / Entrar a Portal** | `E` |
